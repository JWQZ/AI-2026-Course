# Agent（智能体）

本目录用于提交「Agent（智能体）」作业。每组只在本目录下提交自己的 group-XX/ 文件夹。组号以课程分配为准；每组由组长或指定代表提交。

## 组内文件结构

在本目录下建立 group-XX/，建议包含：

- code/：项目源代码及必要配置文件。
- README.md：项目简介、环境要求、安装与使用方法、运行命令和结果展示。
- 其他必要文件：仅放置运行和理解作业所需的文件。

不要提交缓存、临时文件、编译产物、虚拟环境、大型数据集或模型权重。项目专属忽略规则可放在 group-XX/.gitignore 中。

## 提交流程

1. 将课程仓库 Fork 到自己的 GitHub 账号。
2. 在个人 fork 中，从课程指定的基础分支创建 group-XX 分支，例如 group-05。分支名中的组号必须与目录名一致。
3. 在本目录下创建 group-XX/，整理代码、组内 README 和必要文件；不要修改其他组的目录。
4. 在本地检查文件结构、运行说明和结果展示，然后提交并将分支推送到个人 fork。
5. 向课程仓库的 master 分支发起 Pull Request。PR 标题注明任务名称和组号；描述中写明项目内容、运行方法和结果位置。
6. 根据助教在 PR 中的意见，在原分支继续修改并推送，更新会进入同一个 PR。审核通过后等待合并到 master。

## 注意事项

- 不要直接向课程仓库的 master 分支提交，也不要 force push。
- 不要为同一组作业重复创建多个 PR；修改请沿用原 PR。
- 提交路径应为 $folder/group-XX/。如组号或任务目录需要调整，请先联系课程组。

更多课程级提交说明见仓库根目录 [README](../README.md)。
